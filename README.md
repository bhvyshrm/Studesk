# StuDesk 📚

**Your student life, organized in one place.**

StuDesk is a student productivity app designed to help you manage academics, organize learning resources, and keep track of everyday college responsibilities — all in one workspace.

## ✨ Features

- 🏠 **Home** — Keep track of your daily plans and upcoming tasks.
- 🎓 **Academics** — Organize your syllabus, notes, and timetable.
- 📚 **Library** — Keep your study materials and learning resources together.
- 🔔 **Reminders** — Stay aware of important tasks and events.
- 👤 **Profile** — Manage your personal and academic information.
- 🎨 **Modern UI** — Enjoy a clean interface designed for a focused student experience.

## 📱 Download

Download the latest Android APK from the [GitHub Releases](../../releases) page.

1. Download the APK to your Android device.
2. Open the downloaded file.
3. Allow installation from this source if prompted.
4. Install StuDesk and start organizing your student life.

## 🛠️ Built With

- Flutter
- Dart
- Supabase *(for configured backend and authentication services)*

## 🚀 Run Locally

Make sure Flutter and Git are installed.

```bash
git clone <YOUR_REPOSITORY_URL>
cd studesk
flutter pub get
flutter run
```

To build a release APK:

```bash
flutter build apk --release
```

The generated APK can be found at:

```text
build/app/outputs/flutter-apk/app-release.apk
```

## 🔐 Configuration

If your setup uses Supabase or Google authentication, configure the required project settings and environment values before running the app. Never commit private credentials, service-role keys, or signing keys to GitHub.
